# Debug Tuning Matrix

## Scope

当前模拟调参功能覆盖应用内全部核心业务页签，对应模块如下：

1. 连接链路
2. 飞控调参
3. 运行监测
4. 黑匣子
5. 地图回放
6. 固件升级

## Parameters

### 连接链路

- 日志级别
- 首选链路
- 请求超时
- 自动重连

### 飞控调参

- PID 灵敏度
- 滤波强度
- 摇杆 Expo

### 运行监测

- 实时图表
- 刷新频率
- 电压告警

### 黑匣子

- 采样频率
- 调试叠层

### 地图回放

- 播放倍率
- 尾迹长度
- 自动居中

### 固件升级

- 安全刷写
- 分包大小
- 刷写后校验

## Runtime Behavior

- 所有参数在调试环境下均以内存态生效，无需重启应用
- 每次参数变更都会进入运行期日志面板
- 支持单模块重置与全局重置
- 调参页默认采用“高级模式”工作台布局：顶部状态区 + 模块轨道 + 单模块参数区
- 已预留“精简模式”入口，后续可针对新手用户提供裁剪后的操作流
